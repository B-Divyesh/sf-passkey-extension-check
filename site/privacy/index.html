Privacy for your local readiness check.

The extension uses local browser APIs so your diagnostic data does not need to leave your device.

Data the extension accesses

If you allow optional extension-management access, it reads extension names, IDs, enabled state, and install type to identify known providers. It asks documented browser APIs about WebAuthn capability and reads online status.

Data stored locally

Provider selections, recovery selections, capability results, and the last check are stored in extension-local browser storage. “Clear saved check” removes them. Exported reports go only where you save them.

Data we collect

None. There is no account, analytics, telemetry, advertising, or extension backend. The extension has no content scripts and does not read passwords, passkeys, pages, form values, browsing history, or authentication traffic.

Website storage

The website does not set analytics cookies. Its service worker may cache public page files for repeat visits. The demo writes only its named sample key and does not read or write extension storage.

Contact and changes

File questions or proposed changes in the public source repository. Material changes will receive a new effective date.
