Privacy

Passkey Extension Check is designed so your diagnostic data does not need to leave your device.

Data the extension accesses

If you grant the optional extension-management permission, the extension reads installed extension names, IDs, enabled state, and install type to identify known passkey providers. The raw list is discarded after matching. It also asks documented browser APIs about WebAuthn capability and reads online/offline status.

Data stored locally

Provider selections, recovery checklist selections, capability results, and the last-check time are saved in extension-local browser storage. Use “Clear saved check” to erase them. Exported text reports are saved only where you choose.

Data we collect

None. There is no account, analytics, telemetry, advertising, or extension backend. The extension has no content scripts and does not read passwords, passkeys, page contents, form values, browsing history, or authentication traffic.

Website

The website does not set analytics cookies. Its service worker may cache public page assets on your device for faster repeat visits. Hosting infrastructure may retain standard short-lived access logs for security and delivery.

Contact and changes

Questions and proposed changes can be filed in the project’s public source repository. Material policy changes will be dated on this page.
