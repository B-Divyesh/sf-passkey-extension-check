How it works

Check before you remove a fallback.

The extension lists known password-manager extensions when you allow it. You can add providers the browser cannot list.

It checks non-secret WebAuthn capability, then gives a recovery-first checklist. It does not test a real account sign-in.

Three local steps

Run a passkey readiness check.

  1. 01

    List providers

    Allow extension metadata access, or confirm enabled providers yourself.

  2. 02

    Check capability

    Read browser capability without creating a credential or starting a sign-in.

  3. 03

    Plan recovery

    Keep a route back in and export the local checklist before changing login methods.

Privacy

Your report stays on your device.

  • No account or analytics
  • No content scripts on websites
  • No password, passkey, or form access
  • Raw extension inventory is discarded
  • Selections use browser-local storage
  • Text reports are exported locally

Install the extension

Run the check in Chromium.

The download is a Chromium development package. Firefox packaging is not available yet.

  1. Download and unzip the package.
  2. Open chrome://extensions and enable Developer mode.
  3. Choose “Load unpacked,” select the folder, then click the toolbar icon.
